Under the hood

No magic. Just softwareupdate.

01

Ask macOS

Runs softwareupdate --list, the same source System Settings uses.

02

Read each update

Parses label, title, version and whether a restart is required.

03

Compare versions

Checks the update's major version against the macOS you're running.

04

Paint the dot

The most important update wins.

Get it

Install in under a minute.

Download

  1. Download UpdateBar.dmg from the latest release.
  2. Open it and drag UpdateBar onto Applications.
  3. Launch it, then turn on Launch at login from its menu.
First launch: UpdateBar isn't signed with an Apple Developer ID, so macOS blocks it once. Go to System Settings → Privacy & Security and click Open Anyway.
Download .dmg All releases

Build from source

# only the Command Line Tools, no Xcode
$ xcode-select --install
$ git clone https://github.com/AndreaPolazzo/UpdateBar.git
$ cd UpdateBar
$ ./build.sh
✓ Installed and launched: /Applications/UpdateBar.app

The script compiles, signs, installs into Applications and launches the app. The cloned folder isn't needed afterwards.
